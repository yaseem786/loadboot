## Install — Gmail
1. Open the `.html` file in a browser (double-click it).
2. Select everything from the name down to the address line (Ctrl/Cmd+A on the page), copy.
3. Gmail → ⚙ Settings → See all settings → General → **Signature** → Create new → paste → Save changes.
4. Below the box, set "Signature defaults" for new emails and replies.

## Install — Outlook (desktop or web)
Settings → Mail → Compose and reply → Signatures → New → paste the same selection → Save.
