How the link works

Both portals already share one Supabase client. The workspace joins channel dispatch:live: presence (online + which tab) and broadcast events — rc_uploaded, availability_posted, check_call, message, status_change. The CC subscribes; a matching row updates in place and flashes. Polling stays as the fallback, so nothing breaks if the socket drops. Approvals flow back the same way — the dispatcher sees “Approved” the second it happens, not on the next poll.
